## Controlled Actions Implemented

1. **Semantic adjacent-lesson navigation**
   - learner-facing references use “попереднє заняття” and “наступне заняття”;
   - prohibited numbered adjacent-lesson transitions are absent from visible and accessible copy.

2. **Direct Portfolio PDF**
   - primary action is exactly `📥 Завантажити PDF`;
   - PDF is generated locally in the browser;
   - all eight controlled Portfolio fields are included;
   - Ukrainian text is rendered to page canvases before packaging into PDF, avoiding remote font or PDF services;
   - filename excludes the lesson number and may include a sanitized community name.

3. **Unified AI Prompt UX**
   - `👁️ Переглянути запит`;
   - `📋 Скопіювати запит`;
   - success feedback `Скопійовано`;
   - official actions `🤖 Відкрити ChatGPT ↗` and `✨ Відкрити Gemini ↗`;
   - previewed and copied prompt text is generated by the same function;
   - clipboard fallback, accessible dialog and focus return are implemented;
   - no automatic learner-data transmission or submission.

4. **Reset and persistence**
   - progress reset requires confirmation and preserves the Portfolio artifact;
   - a separate danger-labelled action clears the Portfolio only after explicit confirmation;
   - navigation, interactive, test and Portfolio state use a Lesson 02 namespace.
