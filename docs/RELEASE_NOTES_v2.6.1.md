# UCAN Lesson 02 — Release Notes v2.6.1

## Межі релізу

Gold Release v2.6.1 є термінологічним hotfix версії v2.6. Функціональна поведінка, навігація, progress strip, практичне завдання, контракти AI-промптів, логіка копіювання, localStorage, PDF-генератор, CSS та затверджені візуальні assets не змінювалися.

## Термінологічне узгодження

У learner-facing інтерфейсі послідовно використовується термін **«АІ-консультант»**. Попередні українські варіанти вилучено з інтерфейсу, fallback-повідомлення та актуальної релізної документації. Позначку про необов’язковість прибрано із заголовка блоку.

## Змінені файли

- `index.html` — лише learner-facing термінологія;
- `js/script.js` — лише learner-facing fallback-назва, без змін поведінки або промптів;
- `README.md` — версія, термінологія та посилання на актуальні релізні документи;
- `docs/RELEASE_NOTES_v2.5.md` — узгоджено застаріле термінологічне посилання;
- `docs/UCAN_Lesson_02_Consolidated_Corrective_Register_v2.5.md` — узгоджено застарілі термінологічні посилання;
- `docs/UCAN_Lessons_03-26_Standards_Delta_from_Lesson_02_v1.0.md` — зафіксовано learner-facing термін;
- `docs/RELEASE_NOTES_v2.6.1.md` — цей релізний запис;
- `docs/PACKAGE_MANIFEST_v2.6.1.sha256` — актуальні контрольні суми пакета.
