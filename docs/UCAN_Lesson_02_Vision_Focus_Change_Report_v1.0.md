## 1. Перелік змінених місць

### Зміна 1 — Learning Outcome

**Розташування:** `index.html` → сторінка 1 → блок `Після цього заняття Ви зможете`.

**Доданий текст:**

> Уміє сформулювати первинну кліматично нейтральну візію власної громади на основі визначеного виклику, прикладів інших міст та обраних принципів.

**Обґрунтування:**

Доповнення прямо фіксує цільовий навчальний результат і пов’язує концептуальний матеріал, приклади міст та обрані принципи з фінальним формулюванням візії. Наявний результат навчання не змінено.

### Зміна 2 — короткий learner-facing акцент на візії

**Розташування:** `index.html` → сторінка 2 → блок `Від кліматичного виклику до візії громади`, одразу після вступного пояснення кліматично нейтральної логіки рішень.

**Доданий текст:**

> Практичний фокус: результатом цього заняття стане сформульована Вами первинна кліматично нейтральна візія громади — на основі визначеного виклику, прикладів інших міст та обраних принципів.

**Обґрунтування:**

Це найраніший природний перехід від визначеного виклику до практичного результату заняття. Акцент посилює орієнтацію учасника, не створюючи нового розділу, сторінки, вправи чи поля Portfolio.
