# UCAN Lesson 02 — Gold Release Candidate v2.0

## Run

Extract the archive and open `index.html` through an HTTP/HTTPS server. The lesson has no server-side dependency and stores learner data locally in the browser.

## Runtime files

- `index.html`
- `css/style.css`
- `js/script.js`
- `assets/images/` — three approved visual assets

## Documentation

See `docs/` for Release Notes, Changelog, Final QA Report, Regression Checklist, Known Issues and package manifest.

## Privacy

Portfolio and learning progress stay in browser localStorage. AI prompts are copied by the learner and are not transmitted automatically. PDF generation is local.
